# 飞书接入指南

> 本文档介绍如何通过 Web UI 快速接入飞书，实现手机远程控制 AI。

## 🎯 推荐方式：Web UI 扫码接入

**这是最简单的方式，无需手动配置文件！**

### 步骤 1：启动服务

1. 双击 `启动CC-Connect控制面板.vbs`（中文用户）
2. 选择 `[4] Start + Open Browser`
3. 等待浏览器打开 Web UI

### 步骤 2：创建项目

1. 在 Web UI 中点击「项目」菜单
2. 点击「添加项目」按钮
3. 填写项目信息：
   - **项目名称：** 如 `my-project`
   - **工作目录：** 你的项目文件夹路径
   - **Agent 类型：** `claudecode`

### 步骤 3：添加飞书平台

1. 在项目设置中点击「添加平台」
2. 选择「飞书」
3. 点击「扫码创建」按钮
4. 用飞书 App 扫描二维码
5. 完成授权后，配置会自动写入

### 步骤 4：开始使用

1. 在飞书中找到你的机器人
2. 直接发消息开始对话
3. 使用 `/new` 创建新会话
4. 使用 `/list` 查看会话列表

## 🔧 手动配置方式

如果扫码不成功，可以手动配置：

### 步骤 1：创建飞书应用

1. 访问 [飞书开放平台](https://open.feishu.cn/)
2. 登录你的飞书账号
3. 点击右上角「控制台」
4. 点击「创建企业自建应用」
5. 填写应用信息：
   - **应用名称：** 如 `CC Connect`
   - **应用描述：** `AI 远程助手`

### 步骤 2：获取凭证

1. 在应用详情页，点击左侧「凭据与基础信息」
2. 记录以下信息：
   ```
   App ID:     cli_axxxxxxxxxxxx
   App Secret: QhkMpxxxxxxxxxxxxxxxxxxxx
   ```

### 步骤 3：启用机器人能力

1. 左侧导航栏点击「应用能力」→「机器人」
2. 点击「启用机器人」
3. 填写机器人信息：
   - **机器人名称：** 如 `CC Connect`
   - **机器人描述：** `AI 远程助手`

### 步骤 4：配置权限

1. 左侧导航栏点击「权限管理」
2. 搜索并添加以下权限：
   - `contact:user.base:readonly` - 获取用户信息
   - `im:message.group_at_msg:readonly` - 接收群消息
   - `im:message.p2p_msg:readonly` - 接收私聊消息
   - `im:message:send_as_bot` - 发送消息

### 步骤 5：配置事件订阅

1. 左侧导航栏点击「事件与回调」
2. 选择「使用长连接接收事件」
3. 添加事件：`im.message.receive_v1`

### 步骤 6：在 Web UI 中配置

1. 打开 Web UI（http://localhost:9820）
2. 进入项目设置
3. 添加飞书平台
4. 填入 `App ID` 和 `App Secret`

## 💡 使用技巧

### 直接私聊机器人

**推荐方式：** 直接给机器人发私聊消息

```
你：帮我分析一下项目结构
机器人：好的，让我分析一下...
```

### 多会话管理

```
/new 代码重构          # 创建新会话
/new bug修复           # 创建另一个会话
/list                  # 查看所有会话
/switch 1              # 切换到会话 1
```

### 群聊使用

1. 创建飞书群聊
2. 把机器人添加到群里
3. 在群里 @机器人 发消息

## ❓ 常见问题

### Q: 扫码后没有反应？

A: 检查网络连接，重新尝试扫码。

### Q: 机器人没有回复？

A: 
1. 检查 cc-connect 服务是否运行
2. 检查飞书权限是否配置正确
3. 检查事件订阅是否添加

### Q: 如何切换项目？

A: 在 Web UI 中切换项目，或在飞书中使用 `/dir` 命令切换工作目录。
