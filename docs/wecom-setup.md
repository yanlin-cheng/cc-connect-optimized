# 企业微信接入指南

> 本文档介绍如何接入企业微信，实现通过企业微信或个人微信与 AI 对话。

## 🎯 推荐方式：WebSocket 长连接

**无需公网 IP，配置简单！**

### 步骤 1：创建智能机器人

1. 登录 [企业微信管理后台](https://work.weixin.qq.com/wework_admin/frame)
2. 进入 **应用管理** → **智能机器人**
3. 点击 **创建智能机器人**
4. 填写机器人信息：
   - **机器人名称：** 如 `CC Connect`
   - **机器人描述：** `AI 远程助手`

### 步骤 2：获取凭证

创建完成后，记录以下信息：

```
BotID:  xxxxxxxxxxxxxxxx
Secret: xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
```

> ⚠️ **Secret 只会显示一次！** 请立即复制保存。

### 步骤 3：在 Web UI 中配置

1. 打开 Web UI（http://localhost:9820）
2. 进入项目设置
3. 添加企业微信平台
4. 选择「WebSocket」模式
5. 填入 `BotID` 和 `Secret`

### 步骤 4：开始使用

1. 在企业微信中找到你的机器人
2. 直接发消息开始对话
3. 使用 `/new` 创建新会话
4. 使用 `/list` 查看会话列表

---

## 🔧 关联个人微信

**让个人微信也能直接与 AI 对话！**

### 步骤 1：登录企业微信管理后台

1. 进入 **我的企业** → **微信插件**
2. 用个人微信扫描页面上的二维码
3. 关联后，个人微信中会出现企业微信的应用入口

### 步骤 2：在个人微信中使用

1. 打开个人微信
2. 找到企业微信的应用入口
3. 直接发消息给机器人

---

## 💡 使用技巧

### 直接私聊机器人

**推荐方式：** 直接给机器人发私聊消息

```
你：帮我分析一下项目结构
机器人：好的，让我分析一下...
```

### 多会话管理

```
/new 代码重构          # 创建新会话
/new bug修复           # 创建另一个会话
/list                  # 查看所有会话
/switch 1              # 切换到会话 1
```

### 群聊使用

1. 创建企业微信群聊
2. 把机器人添加到群里
3. 在群里 @机器人 发消息

## ❓ 常见问题

### Q: 机器人没有回复？

A:
1. 检查 cc-connect 服务是否运行
2. 检查 BotID 和 Secret 是否正确
3. 检查网络连接

### Q: 个人微信无法使用？

A:
1. 确认已关联微信插件
2. 确认企业微信管理员已开启微信插件功能

### Q: 如何切换项目？

A: 在 Web UI 中切换项目，或在企业微信中使用 `/dir` 命令切换工作目录。
